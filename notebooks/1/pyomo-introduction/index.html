Mathematical Model¶

Let’s start with a purely mathematical example:

min⁡xx12+2x22−x3s.t.x1+x2=1x1+2x2−x3=5−10≤x1,x2,x3≤10\begin{align*} \min_{x} \quad & x_1^2 + 2 x_2^2 - x_3 \\ \mathrm{s.t.} \quad & x_1 + x_2 = 1 \\ & x_1 + 2 x_2 - x_3 = 5 \\ & -10 \leq x_1, x_2, x_3 \leq 10 \end{align*}xmin​s.t.​x12​+2x22​−x3​x1​+x2​=1x1​+2x2​−x3​=5−10≤x1​,x2​,x3​≤10​
(1)

We want to solve the constrained optimization problem numerically.

Visualize the Solution¶

Is our answer correct?

We can solve this optimization problem with guess and check. If we guess x3x_3x3​, we can then solve the constraints for x1x_1x1​ and x2x_2x2​:

Constraints:

x1+x2=1x1+2x2−x3=5\begin{align*} & x_1 + x_2 = 1 \\ & x_1 + 2 x_2 - x_3 = 5 \end{align*}​x1​+x2​=1x1​+2x2​−x3​=5​
(2)
[1112][x1x2]=[15+x3]\begin{bmatrix} 1 & 1 \\ 1 & 2 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \end{bmatrix} = \begin{bmatrix} 1 \\ 5 + x_3 \end{bmatrix}[11​12​][x1​x2​​]=[15+x3​​]
(3)

We can then evaluate the objective. Let’s see the graphical solution to our optimization problem.

Notice the shape of what we are about to draw. Three variables minus two equality constraints leaves exactly one degree of freedom, so the entire feasible set is a curve, and we can plot the objective along it. That is a luxury of a tiny problem: with 26,280 variables there is no curve to look at, which is why we need a solver at all.

Note

We will solve, then extract the answer into plain Python, then plot the extracted results --- three separate cells. That separation is a habit worth forming: you can redraw and relabel the figure as many times as it takes without waiting on the solver, and the extracted numbers can be archived and replotted a year later on a machine with no solver installed. The same pattern is developed at length in Portfolio Optimization.

# ---------- EXTRACT --------------------------------------------------------
# Guess and check: sweep x3, solve the constraints for (x1, x2), evaluate the
# objective. Nothing is plotted here -- this cell only produces numbers.

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def constraints(x3):
    """Solve the linear constraints for x1 and x2, given a guess of x3.

    Args:
        x3: Value for the decision variable x3

    Returns:
        x1 and x2: Values calculated from the constraints
    """

    # Define the matrices in the above equations
    A = np.array([[1, 1], [1, 2]])
    b = np.array([1, 5 + x3])

    # Solve the linear system of equations
    z = np.linalg.solve(A, b)
    x1 = z[0]
    x2 = z[1]
    return x1, x2


def objective(x1, x2, x3):
    """Evaluate the objective function."""
    return x1**2 + 2 * x2**2 - x3


# Guess many values of x3.
x3_guesses = np.linspace(-10, 4, 29)
obj = [objective(*constraints(x3), x3) for x3 in x3_guesses]

# Everything the figure needs, as plain Python: the guess-and-check curve, and
# the point Pyomo/Ipopt found in the cells above.
results = {
    "sweep": helper.table(pd.DataFrame({"x3": x3_guesses, "obj": obj})),
    "solution": helper.extract(m, x1=m.x1, x2=m.x2, x3=m.x3, obj=m.OBJ),
}

An exact check: eliminate the constraints¶

The picture is convincing, but we can do better than convincing. With only one degree of freedom we can solve this problem in closed form and check the solver against algebra rather than against a plot.

Subtracting the first constraint from the second gives x2−x3=4x_2 - x_3 = 4x2​−x3​=4, so

x2=4+x3,x1=1−x2=−3−x3.x_2 = 4 + x_3, \qquad x_1 = 1 - x_2 = -3 - x_3 .x2​=4+x3​,x1​=1−x2​=−3−x3​.
(4)

Substituting into the objective leaves a function of x3x_3x3​ alone:

F(x3)=(3+x3)2+2(4+x3)2−x3=3x32+21x3+41.F(x_3) = (3 + x_3)^2 + 2 (4 + x_3)^2 - x_3 = 3 x_3^2 + 21 x_3 + 41 .F(x3​)=(3+x3​)2+2(4+x3​)2−x3​=3x32​+21x3​+41.
(5)

This is a parabola opening upward — the curve plotted above — so its single stationary point is the minimum:

F′(x3)=6x3+21=0⟹x3=−72,F(−72)=174=4.25,F'(x_3) = 6 x_3 + 21 = 0 \quad \Longrightarrow \quad x_3 = -\tfrac{7}{2}, \qquad F\left(-\tfrac{7}{2}\right) = \tfrac{17}{4} = 4.25 ,F′(x3​)=6x3​+21=0⟹x3​=−27​,F(−27​)=417​=4.25,
(6)

with x1=x2=12x_1 = x_2 = \tfrac{1}{2}x1​=x2​=21​. All three values lie strictly inside [−10,10][-10, 10][−10,10], so no bound is active and this really is the constrained minimum.

Note

Two different things agree here, and it is worth being clear about which is which. The curve above is evaluated by solving the linear system for each guess of x3x_3x3​; the algebra here eliminates the constraints symbolically. They agree only if the elimination is right — and both agree with Ipopt. That is the kind of independent check worth building into your own work, because a solver returning optimal tells you the solver was happy, not that you wrote down the model you meant.

Later in the semester we will see why this trick does not scale: eliminating the constraints requires solving them, which is easy for a 2×22 \times 22×2 linear system and impossible in general.
