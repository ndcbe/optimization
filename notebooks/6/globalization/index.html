Geometric Insights into Newton Steps¶

Motivation¶

We can interpret Newton-type methods for unconstrained optimization as root finding of ∇f(x)=0\nabla f(x) = 0∇f(x)=0.

At iteration kkk, we assemble an approximation to f(x)f(x)f(x) using a Taylor series expansion:

f(xk+pk)≈f(xk)+∇f(xk)Tpk+12(pk)T(Bk)pkf(x^k + p^k) \approx f(x^k) + \nabla f(x^k)^T p^k + \frac{1}{2} (p^k)^T (B^k) p^kf(xk+pk)≈f(xk)+∇f(xk)Tpk+21​(pk)T(Bk)pk
(4)

and solve for pkp^kpk such that ∇f(xk+pk)=0\nabla f(x^k + p^k)=0∇f(xk+pk)=0. This gives:

pk=−(Bk)−1∇f(xk)p^k = -(B^k)^{-1} \nabla f(x^k)pk=−(Bk)−1∇f(xk)
(5)

The choice of BkB^kBk determines the algorithm classification:

  • Pure Newton Method, Bk=∇2f(xk)B^k = \nabla^2 f(x^k)Bk=∇2f(xk)

  • Steepest Descent, Bk=1αIB^k = \frac{1}{\alpha} IBk=α1​I, where scalar α\alphaα is sometimes known as the dampening factor

  • Levenberg-Marquardt, Bk=∇2f(xk)+δIB^k = \nabla^2 f(x^k) + \delta IBk=∇2f(xk)+δI, where scalar δ\deltaδ is chosen to ensure BkB^kBk is positive definite.

  • Broyden Methods, BkB^{k}Bk is approximated using history of gradient evaluations, i.e., ∇f(x0),...∇f(xk)\nabla f(x^0), ... \nabla f(x^k)∇f(x0),...∇f(xk). We will study the SR1 and BFGS formulas in this family of methods.

This section explores how choosing BkB^kBk impacts the shape of the approximation and calculated step.

Descent Properties¶

For pk=−(Bk)−1∇f(xk)p^k=-(B^k)^{-1}\nabla f(x^k)pk=−(Bk)−1∇f(xk), positive definiteness of BkB^kBk gives

∇f(xk)Tpk=−∇f(xk)T(Bk)−1∇f(xk)<0.\nabla f(x^k)^T p^k=-\nabla f(x^k)^T(B^k)^{-1}\nabla f(x^k)<0.∇f(xk)Tpk=−∇f(xk)T(Bk)−1∇f(xk)<0.
(6)

Thus pkp^kpk is a descent direction whenever ∇f(xk)≠0\nabla f(x^k)\ne0∇f(xk)=0. A line search still chooses a step length that produces sufficient decrease. (Biegler, Eqs. 3.2--3.5, p. 41.)

Line Search¶

Excerpts from Section 3.4 in Biegler (2010).

The Wolfe conditions require that (3.31) be satisfied as well as

∇f(xk+αkpk)Tpk≥ζ∇f(xk)Tpk\begin{align} \nabla f(x^k + \alpha^k p^k)^T p^k &\geq \zeta \nabla f(x^k)^T p^k \tag{3.32} \end{align}∇f(xk+αkpk)Tpk​≥ζ∇f(xk)Tpk​(3.32)​
(7)

for ζ∈(η,1)\zeta \in (\eta, 1)ζ∈(η,1). From Figure 3.2, we see that α∈[αw,αa]\alpha \in [\alpha_w, \alpha_a]α∈[αw​,αa​] satisfies these conditions.

The strong Wolfe conditions are more restrictive and require satisfaction of

∣∇f(xk+αkpk)Tpk∣≤ζ∣∇f(xk)Tpk∣\begin{align} |\nabla f(x^k + \alpha^k p^k)^T p^k| &\leq \zeta |\nabla f(x^k)^T p^k| \tag{3.33} \end{align}∣∇f(xk+αkpk)Tpk∣​≤ζ∣∇f(xk)Tpk∣​(3.33)​

Global convergence result¶

Under the standard smoothness and bounded-level-set assumptions, a Goldstein--Armijo line search satisfies the Zoutendijk condition

∑k=0∞cos⁡2(θk) ∥∇f(xk)∥2<∞,\sum_{k=0}^{\infty}\cos^2(\theta^k)\,\|\nabla f(x^k)\|^2<\infty,k=0∑∞​cos2(θk)∥∇f(xk)∥2<∞,
(10)

where θk\theta^kθk is the angle between pkp^kpk and −∇f(xk)-\nabla f(x^k)−∇f(xk). If those angles stay bounded away from 90∘90^\circ90∘, the gradient norm tends to zero. (Biegler, Theorem 3.3, pp. 48--49; Nocedal and Wright, Theorem 3.2, p. 38.)

Backtracking line search¶

  1. Compute a descent direction pkp^kpk and start with α=1\alpha=1α=1.

  2. While the Armijo condition fails, reduce α←ρα\alpha\leftarrow\rho\alphaα←ρα for 0<ρ<10<\rho<10<ρ<1.

  3. Accept αk=α\alpha^k=\alphaαk=α and set xk+1=xk+αkpkx^{k+1}=x^k+\alpha^k p^kxk+1=xk+αkpk.

When α<1\alpha<1α<1, also guard against a step that is unnecessarily short, for example with a Wolfe or Goldstein condition. (Biegler, Algorithm 3.2, p. 50.)

Recovery of the fast local rate¶

If the iterates converge to a strict local minimizer and the Hessian approximations satisfy the Dennis--Moré condition

∥(Bk−∇2f(xk))pk∥∥pk∥→0,\frac{\|(B^k-\nabla^2 f(x^k))p^k\|}{\|p^k\|}\to0,∥pk∥∥(Bk−∇2f(xk))pk∥​→0,
(11)

then the full step αk=1\alpha^k=1αk=1 is eventually accepted and convergence is superlinear. (Biegler, Theorem 3.4, p. 50.)

def plot_alpha(xk, eta_ls=0.25, algorithm="newton", alpha_max=1.0):
    """
    Calculate step and visualize line search conditions

    Arguments:
        xk : initial point (required)
        eta_ls : eta in Goldstein-Armijo conditions
        algorithm : either "newton" or "steepest-descent"
        alpha_max : plots alpha between 0 and alpha_max

    Returns:
        Nothing

    Creates:
        Plot showing function value and line search conditions as a function of alpha
    """

    fxk = f(xk)
    dfxk = df(xk)

    if algorithm == "newton":
        pk = -dfxk / ddf(xk)
    elif algorithm == "steepest-descent":
        pk = -dfxk
    else:
        raise ValueError(
            "algorithm argument must be either 'newton' or 'steepest-descent'"
        )

    print("Considering xk =", xk, "and f(xk) = ", fxk)
    print("Step with", algorithm, "algorithm:")
    print("pk = ", pk)
    print("With full step, xk+1 =", pk + xk, "and f(xk+1) =", f(xk + pk))

    n = 100
    alpha = np.linspace(0, alpha_max, n)
    fval = np.zeros(n)

    for i in range(0, n):
        fval[i] = f(xk + alpha[i] * pk)

    fs = 18
    plt.figure()

    # Evaluate f(x^{k+1}) for different alpha values.
    # Color and linestyle match figures/plots/line-search-conditions.py, the
    # static version of this figure in the course pack: house cycle in order,
    # black solid, blue dashed, orange dash-dot. The linestyles are what make
    # the three series separable in greyscale.
    plt.plot(alpha, fval, color="black", linestyle="-", label=r"$f(x^{k+1})$")

    # Armijo condition
    arm = np.zeros(n)
    for i in range(0, n):
        arm[i] = fxk + eta_ls * alpha[i] * dfxk * pk

    plt.plot(alpha, arm, color="#0072B2", linestyle="--", label="Armijo")

    # Goldstein condition
    gold = np.zeros(n)
    for i in range(0, n):
        gold[i] = fxk + (1 - eta_ls) * alpha[i] * dfxk * pk

    plt.plot(alpha, gold, color="#E69F00", linestyle="-.", label="Goldstein")

    # Apply backtracking linestep (starting with alpha = alpha_max)
    i = n - 1
    flag = True
    failed = False
    while flag:

        if i < n - 1 and fval[i] < gold[i]:
            flag = False
            print(
                "Line search failed. Goldstein conditions violated. Consider increasing alpha_max."
            )
            failed = True

        # Armijo condition
        if fval[i] < arm[i]:
            flag = False
        else:
            i = i - 1

        if i < 0:
            print("Line search failed. Try decreasing alpha_max.")
            failed = True
            # Stop here. Without this, the loop keeps going with a negative
            # index, which wraps around to the end of the array and reports a
            # second, contradictory diagnosis.
            flag = False

    if not failed:
        print(
            "alphak =",
            alpha[i],
            "with backtracking line search starting at alpha =",
            alpha_max,
        )
        print("f(xk + alphak*pk) =", fval[i])

        plt.scatter(
            alpha[i],
            fval[i],
            marker="x",
            color="black",
            label=r"$\alpha^{k}$ for line search",
        )

    # Labels
    plt.xlabel(r"$\alpha^k$", fontsize=fs)
    plt.ylabel(r"$f(x^k + \alpha^k p^k)$", fontsize=fs)
    plt.grid()
    plt.legend()
    plt.show()

Trust Regions¶

Excerpts from Section 3.5 in Biegler (2010).

Main Idea and General Algorithm¶

At iteration kkk, minimize a local quadratic model only where it is trusted:

min⁡p  mk(p)=∇f(xk)Tp+12pTBkps.t.∥p∥≤Δk.\min_p\;m^k(p)=\nabla f(x^k)^Tp+\tfrac12p^TB^kp\qquad\text{s.t.}\qquad\|p\|\le\Delta^k.pmin​mk(p)=∇f(xk)Tp+21​pTBkps.t.∥p∥≤Δk.
(12)

The radius Δk\Delta^kΔk is updated by comparing the objective’s actual reduction with the model’s predicted reduction. (Biegler, Eq. 3.49, p. 53.)

For each iteration:

  1. Solve the trust region subproblem for pkp^kpk.

  2. Compute ρk=actual reduction/predicted reduction\rho^k=\text{actual reduction}/\text{predicted reduction}ρk=actual reduction/predicted reduction.

  3. Shrink Δk\Delta^kΔk when the model predicts poorly; expand it after a good boundary step; otherwise retain it.

  4. Accept xk+pkx^k+p^kxk+pk only when ρk\rho^kρk exceeds the acceptance threshold.

This separates step computation from step acceptance. (Biegler, Algorithm 3.3, p. 53.)

Trust Region Variations¶

The Levenberg--Marquardt path varies a multiplier continuously; dogleg uses straight segments connecting the origin, Cauchy step, and Newton step.

pCp^CpC: Cauchy step

pNp^NpN: Newton step

Levenberg-Marquardt¶

A feasible step pkp^kpk solves the trust region subproblem if and only if some δ≥0\delta\ge0δ≥0 satisfies

(Bk+δI)pk=−∇f(xk),δ(Δk−∥pk∥)=0,Bk+δI⪰0.(B^k+\delta I)p^k=-\nabla f(x^k),\qquad\delta(\Delta^k-\|p^k\|)=0,\qquad B^k+\delta I\succeq0.(Bk+δI)pk=−∇f(xk),δ(Δk−∥pk∥)=0,Bk+δI⪰0.
(13)

  • truncate the Cauchy direction when Δk≤∥pC∥\Delta^k\le\|p^C\|Δk≤∥pC∥;

Dogleg is inexpensive but generally approximates, rather than exactly solves, the trust region subproblem.
