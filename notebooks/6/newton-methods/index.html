Newton models for equations and optimization¶

A row-oriented Jacobian for equations¶

Let D⊆RnD\subseteq\mathbb R^nD⊆Rn be open and F:D→Rn\mathbf F:D\to\mathbb R^nF:D→Rn differentiable. Define (JF(x))ij=∂Fi(x)/∂xj(\mathbf J_F(\mathbf x))_{ij}=\partial F_i(\mathbf x)/\partial x_j(JF​(x))ij​=∂Fi​(x)/∂xj​ for i,j∈{1,…,n}i,j\in\{1,\ldots,n\}i,j∈{1,…,n}. Linearizing at fixed xk\mathbf x^kxk gives

F(xk+p)=F(xk)+JF(xk)p+O(∥p∥2),\mathbf F(\mathbf x^k+\mathbf p)=\mathbf F(\mathbf x^k)+\mathbf J_F(\mathbf x^k)\mathbf p+O(\|\mathbf p\|^2),F(xk+p)=F(xk)+JF​(xk)p+O(∥p∥2),
(1)

with the quadratic remainder when the Jacobian is locally Lipschitz. Newton sets the linear model to zero and solves

JF(xk)pk=−F(xk),xk+1=xk+pk.\mathbf J_F(\mathbf x^k)\mathbf p^k=-\mathbf F(\mathbf x^k),\qquad \mathbf x^{k+1}=\mathbf x^k+\mathbf p^k.JF​(xk)pk=−F(xk),xk+1=xk+pk.
(2)

The actual residual at the update need not be zero. The row-oriented Jacobian requires no extra transpose. An inverse is useful in analysis, but a numerical implementation solves the linear system.

A quadratic model for a scalar objective¶

For f∈C2(D)f\in C^2(D)f∈C2(D) on an open DDD, write gk=∇f(xk)\mathbf g^k=\nabla f(\mathbf x^k)gk=∇f(xk) and Gk=∇2f(xk)\mathbf G^k=\nabla^2f(\mathbf x^k)Gk=∇2f(xk). With xk\mathbf x^kxk fixed,

mk(p)=f(xk)+(gk)Tp+12pTGkp.m_k(\mathbf p)=f(\mathbf x^k)+(\mathbf g^k)^T\mathbf p+\tfrac12\mathbf p^T\mathbf G^k\mathbf p.mk​(p)=f(xk)+(gk)Tp+21​pTGkp.
(3)

Differentiating the model with respect to the chosen displacement gives

∇pmk=gk+Gkp,Gkpk=−gk.\nabla_{\mathbf p}m_k=\mathbf g^k+\mathbf G^k\mathbf p,\qquad \mathbf G^k\mathbf p^k=-\mathbf g^k.∇p​mk​=gk+Gkp,Gkpk=−gk.
(4)

This computes a model stationary point. It is the model minimum if Gk≻0\mathbf G^k\succ0Gk≻0. The model equals a quadratic objective exactly; for a nonlinear objective with locally Lipschitz Hessian its value remainder is O(∥p∥3)O(\|\mathbf p\|^3)O(∥p∥3).

Sources: Biegler (2010), Eqs. (2.37)–(2.39), pp. 34–35; Nocedal and Wright (2006), §11.1, pp. 274–277. The gradient in the numerical examples below is a column vector.

Curvature, descent, and step length¶

A strict local minimum need not have a positive-definite Hessian: f(x)=x4f(x)=x^4f(x)=x4 at zero is a counterexample. The sufficient second-order conditions explicitly require a zero gradient and positive-definite Hessian. Continuity then preserves positive definiteness in a small neighborhood.

For g≠0\mathbf g\ne0g=0, a direction is descent when gTp<0\mathbf g^T\mathbf p<0gTp<0. If G≻0\mathbf G\succ0G≻0 and Gp=−g\mathbf G\mathbf p=-\mathbf gGp=−g, then

gTp=−pTGp<0.\mathbf g^T\mathbf p=-\mathbf p^T\mathbf G\mathbf p<0.gTp=−pTGp<0.
(5)

This guarantees decrease for sufficiently small positive step lengths. It does not guarantee decrease for every α∈(0,1]\alpha\in(0,1]α∈(0,1]. For a C2C^2C2 objective, the exact Taylor identity is

f(x+αp)−f(x)=α∇f(x)Tp+12α2pT∇2f(x+tαp)p,t∈(0,1).f(\mathbf x+\alpha\mathbf p)-f(\mathbf x) =\alpha\nabla f(\mathbf x)^T\mathbf p +\tfrac12\alpha^2\mathbf p^T\nabla^2f(\mathbf x+t\alpha\mathbf p)\mathbf p, \quad t\in(0,1).f(x+αp)−f(x)=α∇f(x)Tp+21​α2pT∇2f(x+tαp)p,t∈(0,1).
(6)

At fixed x,p\mathbf x,\mathbf px,p, the negative O(α)O(\alpha)O(α) term dominates the bounded O(α2)O(\alpha^2)O(α2) remainder for small α\alphaα. The intermediate point includes α\alphaα.

A singular Hessian does not specify a unique basic Newton step. An indefinite Hessian can produce an ascent direction; an inaccurate positive-definite model can still overshoot. These are distinct reasons to modify curvature or control the accepted step length.

Sources: Biegler (2010), Eq. (2.40), p. 34, and §3.1, pp. 39–40; Nocedal and Wright (2006), pp. 22 and 46–47.

Algorithm 2.1: basic unit-step Newton¶

The following reference version adapts Biegler’s Algorithm 2.1 so each quantity is evaluated before it is tested.

  1. Choose x0\mathbf x^0x0, gradient tolerance ϵg\epsilon_gϵg​, and step tolerance ϵp\epsilon_pϵp​.

  2. Evaluate gk\mathbf g^kgk and Gk\mathbf G^kGk. A small gradient reports an approximately stationary candidate.

  3. If the Hessian is singular, report failure of the basic solve; otherwise solve Gkpk=−gk\mathbf G^k\mathbf p^k=-\mathbf g^kGkpk=−gk.

  4. A small step reports limited numerical movement, together with the current gradient norm.

  5. Otherwise take xk+1=xk+pk\mathbf x^{k+1}=\mathbf x^k+\mathbf p^kxk+1=xk+pk and repeat.

A candidate must still be classified; neither a small step nor an approximate Hessian proves a minimum. The diagnostic implementation below retains a post-step convergence test and also checks NaN derivatives, severe conditioning, and an iteration limit. Its experiments deliberately include failure cases.

Source: Biegler (2010), Algorithm 2.1, p. 35.

Helper Function¶

## Calculate gradient with central finite difference
def my_grad_approx(x, f, eps1, verbose=False):
    """
    Calculate gradient of function my_f using central difference formula

    Inputs:
        x - point for which to evaluate gradient
        f - function to consider
        eps1 - perturbation size

    Outputs:
        grad - gradient (vector)
    """

    n = len(x)
    grad = np.zeros(n)

    if verbose:
        print("***** my_grad_approx at x = ", x, "*****")

    for i in range(0, n):

        # Create vector of zeros except eps in position i
        e = np.zeros(n)
        e[i] = eps1

        # Finite difference formula
        my_f_plus = f(x + e)
        my_f_minus = f(x - e)

        # Diagnostics
        if verbose:
            print("e[", i, "] = ", e)
            print("f(x + e[", i, "]) = ", my_f_plus)
            print("f(x - e[", i, "]) = ", my_f_minus)

        grad[i] = (my_f_plus - my_f_minus) / (2 * eps1)

    if verbose:
        print("***** Done. ***** \n")

    return grad


## Calculate gradient using central finite difference and my_hes_approx
def my_hes_approx(x, grad, eps2):
    """
    Calculate Hessian of function my_f using central difference formula and my_grad

    Inputs:
        x - point for which to evaluate gradient
        grad - function to calculate the gradient
        eps2 - perturbation size (for Hessian NOT gradient approximation)

    Outputs:
        H - Hessian (matrix)
    """

    n = len(x)
    H = np.zeros([n, n])

    for i in range(0, n):
        # Create vector of zeros except eps in position i
        e = np.zeros(n)
        e[i] = eps2

        # Evaluate gradient twice
        grad_plus = grad(x + e)
        grad_minus = grad(x - e)

        # Notice we are building the Hessian by column (or row)
        H[:, i] = (grad_plus - grad_minus) / (2 * eps2)

    return H


def check_nan(A):
    return np.sum(np.isnan(A))


## Analyze Hessian.
def analyze_hes(B):
    print(B, "\n")

    if not check_nan(B):
        # Calculate eigenvalues
        l = linalg.eigvals(B)
        print("Eigenvalues: ", l, "\n")

Algorithm 1 Python Implementation¶

## Implement Alg 1 in a function
def alg1(x0, calc_f, calc_grad, calc_hes, eps1, eps2, verbose=False, max_iter=250):
    """
    Arguments:
        x0 - starting point
        calc_f - function that calculates f(x)
        calc_grad - function that calculates gradient(x)
        calc_hes - function that calculates hessian(x)

    Outputs:
        x - iteration history of x (decision variables)
        f - iteration history of f(x) (objective value)
        p - iteration history of p (steps)
    """

    # Allocate outputs as empty lists
    x = []
    f = []
    p = []

    # Store starting point
    x.append(x0)
    k = 0

    flag = True

    print("Iter. \tf(x) \t\t||grad(x)|| \t||p|| \t\tmin(lambda)")

    while flag:
        # Evaluate f(x) at current iteration
        f.append(calc_f(x[k]))

        # Evaluate gradient
        grad = calc_grad(x[k])

        if check_nan(grad):
            print("WARNING: gradient calculation returned NaN")
            break

        # Evaluate Hessian
        hes = calc_hes(x[k])

        if check_nan(hes):
            print("WARNING: Hessian calculation returned NaN")
            break

        if verbose:
            print("\n")
            print("k = ", k)
            print("x = ", x[k])
            print("grad = ", grad)
            print("hes = \n", hes)

        # Check if singular via condition number
        c = np.linalg.cond(hes)
        if c > 1e12:
            flag = False
            print("Warning: Hessian is near singular.")

        else:
            # Calculate step

            p.append(linalg.solve(hes, -grad))

            if verbose:
                print("p = ", p[k])

            # Take step. x[k+1] = x[k] + p[k]
            x.append(x[k] + p[k])

            # Calculate norms
            norm_p = linalg.norm(p[k])
            norm_g = linalg.norm(grad)

            # Calculate eigenvalues (for display only)
            ev = np.real(linalg.eigvals(hes))

            # print("k = ",k,"\t"f[k],"\t",norm_g,"\t",norm_p)
            print(
                k,
                "  \t{0: 1.4e} \t{1:1.4e} \t{2:1.4e} \t{3: 1.4e}".format(
                    f[k], norm_g, norm_p, np.min(ev)
                ),
            )

            # Check convergence criteria
            flag = (norm_p > eps1) and (norm_g > eps2)

            # Update iteration counter
            k = k + 1

        if k > max_iter:
            flag = False
            print("Maximum number of iterations.")
    print("Done.")
    print("x* = ", x[-1])

    return x, f, p

Quantified rates of convergence¶

Let xk→x∗\mathbf x^k\to\mathbf x^*xk→x∗ and ek=∥xk−x∗∥e_k=\|\mathbf x^k-\mathbf x^*\|ek​=∥xk−x∗∥. The convergence is at least Q-linear when

∃r∈(0,1), k0∈N:∀k≥k0,ek+1≤rek.\exists r\in(0,1),\ k_0\in\mathbb N:\quad\forall k\ge k_0,\quad e_{k+1}\le r e_k.∃r∈(0,1), k0​∈N:∀k≥k0​,ek+1​≤rek​.
(7)

It is at least Q-quadratic when

∃K>0, k0∈N:∀k≥k0,ek+1≤Kek2.\exists K>0,\ k_0\in\mathbb N:\quad\forall k\ge k_0,\quad e_{k+1}\le K e_k^2.∃K>0, k0​∈N:∀k≥k0​,ek+1​≤Kek2​.

These are eventual upper bounds; a sequence can satisfy a stronger rate too. For ek=10−3e_k=10^{-3}ek​=10−3, r=0.5r=0.5r=0.5 gives ek+1≤5×10−4e_{k+1}\le5\times10^{-4}ek+1​≤5×10−4, while K=1K=1K=1 gives ek+1≤10−6e_{k+1}\le10^{-6}ek+1​≤10−6. ## Define Python function to calculate objective
def my_f(x, verbose=False):
    """Evaluate function given above at point x

    Inputs:
        x - vector with 2 elements

    Outputs:
        f - function value (scalar)
    """
    # Constants
    a = np.array([0.3, 0.6, 0.2])
    b = np.array([5, 26, 3])
    c = np.array([40, 1, 10])

    # Intermediates. Recall Python indices start at 0
    u = x[0] - 0.8
    s = np.sqrt(1 - u)
    s2 = np.sqrt(1 + u)
    v = x[1] - (a[0] + a[1] * u**2 * s - a[2] * u)
    alpha = (
        -b[0] + b[1] * u**2 * s2 + b[2] * u
    )  # September 5, 2018: changed 's' to 's2'
    beta = c[0] * v**2 * (1 - c[1] * v) / (1 + c[2] * u**2)
    f = alpha * np.exp(-beta)

    if verbose:
        print("##### my_f at x = ", x, "#####")
        print("u = ", u)
        print("sqrt(1-u) = ", s)
        print("sqrt(1+u) = ", s2)
        print("v = ", v)
        print("alpha = ", alpha)
        print("beta = ", beta)
        print("f(x) = ", f)
        print("##### Done. #####\n")

    return f

def adjusted_hes(x, grad, eps2, eps3, verbose=False):

    # Estimate Hessian with finite difference
    hes = my_hes_approx(x, grad, eps2)

    # Calculate eigenvalues
    l, V = linalg.eig(hes)
    smallest_ev = np.min(np.real(l))

    # Calculate modification
    delta = 0
    if smallest_ev - eps3 < 0:
        delta = -smallest_ev + eps3

    if verbose:
        print("Added ({0:1.4e})*I in LM correction.".format(delta))

    # Adjust hessian with Levenberg-Marquardt Correction
    return V.dot(np.diag(np.real(l)) + delta * np.eye(len(x))).dot(V.T)
