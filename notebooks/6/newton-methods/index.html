Newton Method Derivation and Properties¶

Nonlinear System of Equations¶

Consider the system of nonlinear equations f(x):Rn→Rnf(x): \mathbb{R}^n \rightarrow \mathbb{R}^nf(x):Rn→Rn

f(x)=0f(x) = 0f(x)=0
(1)

How to solve numerically? Step 1. Write the Taylor series expansion:

f(x+p)=f(x)+∇f(x)Tp+O(∥p∥2)f(x + p) = f(x) + \nabla f(x)^T p + \mathcal{O}(\|p\|^2)f(x+p)=f(x)+∇f(x)Tp+O(∥p∥2)
(2)

Step 2. Truncate, set f(x+p)=0f(x + p) = 0f(x+p)=0, and solve for ppp:

−f(x)=∇f(x)Tp- f(x) = \nabla f(x)^T p−f(x)=∇f(x)Tp

Important Issues:¶

  • Near a strict local minimizer and with small ∥p∥\| p \|∥p∥, truncation error O(∥p∥3)\mathcal{O}(\| p \|^3)O(∥p∥3) is negligible, and f(x)f(x)f(x) behaves like a quadratic function. We’ll revisit convergence rates soon.

  • ∇2f(x)\nabla^2 f(x)∇2f(x) needs to be nonsingular to compute the Newton step. If ∇2f(x)\nabla^2 f(x)∇2f(x) is singular, some corrections can be applied.

  • Recall that in the neighborhood N(x∗)\mathcal{N}(x^*)N(x∗) of a strict local minimizer, ∇2f(x)\nabla^2 f(x)∇2f(x) is positive definite. Thus, it is desirable for an approximation to ∇2f(x)\nabla^2 f(x)∇2f(x) to also be positive definite (P.D.). We’ll revisit this later today and in the next lecture.

  • To promote convergence, it is important that ppp is a descent step, i.e.,

∇f(x)Tp<0\nabla f(x)^T p < 0∇f(x)Tp<0
(9)

and thus

f(xk)>f(xk+1)f(x^k) > f(x^{k+1})f(xk)>f(xk+1)
(10)

If xk∈N(x∗)x^k \in \mathcal{N}(x^*)xk∈N(x∗) and xk+1=xk+αpx^{k+1} = x^k + \alpha pxk+1=xk+αp, where α∈(0,1]\alpha \in (0, 1]α∈(0,1], then a descent step requires:

0>f(xk+αp)−f(xk)=α∇f(xk)Tp+α22pT∇2f(x+tαp)p0 > f(x^k + \alpha p) - f(x^k) = \alpha \nabla f(x^k)^T p + \frac{\alpha^2}{2} p^T \nabla^2 f(x + t \alpha p) p0>f(xk+αp)−f(xk)=α∇f(xk)Tp+2α2​pT∇2f(x+tαp)p
(11)

for some t∈(0,1)t \in (0, 1)t∈(0,1).

If x∗x^*x∗ is a strict local minimizer and N(x∗)\mathcal{N}(x^*)N(x∗) is sufficiently small, then ∇2f(x+tp)\nabla^2 f(x + t p)∇2f(x+tp) is positive definite, i.e.,

pT∇2f(x+tp)p>0p^T \nabla^2 f(x + t p) p > 0pT∇2f(x+tp)p>0
(12)

This implies ∇f(x)Tp<0\nabla f(x)^T p < 0∇f(x)Tp<0.

Algorithm 2.1: Basic Newton Method¶

Choose a starting point x0x^0x0.

For k≥0k \geq 0k≥0 while ∥pk∥>ϵ1\| p^k \| > \epsilon_1∥pk∥>ϵ1​ and ∥∇f(xk)∥>ϵ2\| \nabla f(x^k) \| > \epsilon_2∥∇f(xk)∥>ϵ2​:

  1. At xkx^kxk, evaluate ∇f(xk)\nabla f(x^k)∇f(xk) and ∇2f(xk)\nabla^2 f(x^k)∇2f(xk). If ∇2f(xk)\nabla^2 f(x^k)∇2f(xk) is singular, STOP.

  2. Solve the linear system ∇2f(xk)pk=−∇f(xk)\nabla^2 f(x^k) p^k = -\nabla f(x^k)∇2f(xk)pk=−∇f(xk).

  3. Set xk+1=xk+pkx^{k+1} = x^k + p^kxk+1=xk+pk and k=k+1k = k + 1k=k+1.

This basic algorithm has the desirable property of fast convergence, which can be quantified by the following well-known property.

## Calculate gradient with central finite difference
def my_grad_approx(x, f, eps1, verbose=False):
    """
    Calculate gradient of function my_f using central difference formula

    Inputs:
        x - point for which to evaluate gradient
        f - function to consider
        eps1 - perturbation size

    Outputs:
        grad - gradient (vector)
    """

    n = len(x)
    grad = np.zeros(n)

    if verbose:
        print("***** my_grad_approx at x = ", x, "*****")

    for i in range(0, n):

        # Create vector of zeros except eps in position i
        e = np.zeros(n)
        e[i] = eps1

        # Finite difference formula
        my_f_plus = f(x + e)
        my_f_minus = f(x - e)

        # Diagnostics
        if verbose:
            print("e[", i, "] = ", e)
            print("f(x + e[", i, "]) = ", my_f_plus)
            print("f(x - e[", i, "]) = ", my_f_minus)

        grad[i] = (my_f_plus - my_f_minus) / (2 * eps1)

    if verbose:
        print("***** Done. ***** \n")

    return grad


## Calculate gradient using central finite difference and my_hes_approx
def my_hes_approx(x, grad, eps2):
    """
    Calculate Hessian of function my_f using central difference formula and my_grad

    Inputs:
        x - point for which to evaluate gradient
        grad - function to calculate the gradient
        eps2 - perturbation size (for Hessian NOT gradient approximation)

    Outputs:
        H - Hessian (matrix)
    """

    n = len(x)
    H = np.zeros([n, n])

    for i in range(0, n):
        # Create vector of zeros except eps in position i
        e = np.zeros(n)
        e[i] = eps2

        # Evaluate gradient twice
        grad_plus = grad(x + e)
        grad_minus = grad(x - e)

        # Notice we are building the Hessian by column (or row)
        H[:, i] = (grad_plus - grad_minus) / (2 * eps2)

    return H


def check_nan(A):
    return np.sum(np.isnan(A))


## Analyze Hessian.
def analyze_hes(B):
    print(B, "\n")

    if not check_nan(B):
        # Calculate eigenvalues
        l = linalg.eigvals(B)
        print("Eigenvalues: ", l, "\n")

Algorithm 1 Python Implementation¶

## Implement Alg 1 in a function
def alg1(x0, calc_f, calc_grad, calc_hes, eps1, eps2, verbose=False, max_iter=250):
    """
    Arguments:
        x0 - starting point
        calc_f - function that calculates f(x)
        calc_grad - function that calculates gradient(x)
        calc_hes - function that calculates hessian(x)

    Outputs:
        x - iteration history of x (decision variables)
        f - iteration history of f(x) (objective value)
        p - iteration history of p (steps)
    """

    # Allocate outputs as empty lists
    x = []
    f = []
    p = []

    # Store starting point
    x.append(x0)
    k = 0

    flag = True

    print("Iter. \tf(x) \t\t||grad(x)|| \t||p|| \t\tmin(lambda)")

    while flag:
        # Evaluate f(x) at current iteration
        f.append(calc_f(x[k]))

        # Evaluate gradient
        grad = calc_grad(x[k])

        if check_nan(grad):
            print("WARNING: gradient calculation returned NaN")
            break

        # Evaluate Hessian
        hes = calc_hes(x[k])

        if check_nan(hes):
            print("WARNING: Hessian calculation returned NaN")
            break

        if verbose:
            print("\n")
            print("k = ", k)
            print("x = ", x[k])
            print("grad = ", grad)
            print("hes = \n", hes)

        # Check if singular via condition number
        c = np.linalg.cond(hes)
        if c > 1e12:
            flag = False
            print("Warning: Hessian is near singular.")

        else:
            # Calculate step

            p.append(linalg.solve(hes, -grad))

            if verbose:
                print("p = ", p[k])

            # Take step. x[k+1] = x[k] + p[k]
            x.append(x[k] + p[k])

            # Calculate norms
            norm_p = linalg.norm(p[k])
            norm_g = linalg.norm(grad)

            # Calculate eigenvalues (for display only)
            ev = np.real(linalg.eigvals(hes))

            # print("k = ",k,"\t"f[k],"\t",norm_g,"\t",norm_p)
            print(
                k,
                "  \t{0: 1.4e} \t{1:1.4e} \t{2:1.4e} \t{3: 1.4e}".format(
                    f[k], norm_g, norm_p, np.min(ev)
                ),
            )

            # Check convergence criteria
            flag = (norm_p > eps1) and (norm_g > eps2)

            # Update iteration counter
            k = k + 1

        if k > max_iter:
            flag = False
            print("Maximum number of iterations.")
    print("Done.")
    print("x* = ", x[-1])

    return x, f, p

Quadratic Convergence Proof¶

Theorem 2.20 (Biegler, 2010)

Assume that f(x)f(x)f(x) is twice differentiable and ∇2f(x)\nabla^2 f(x)∇2f(x) is Lipschitz continuous in a neighborhood of the solution x∗x^*x∗, which satisfies the sufficient second-order conditions. Then, by applying Algorithm 2.1 and with a sufficiently close x0x_0x0​, there exists a constant L^>0\hat{L} > 0L^>0 such that:

  1. The convergence rate for {xk}\{x^k\}{xk} is quadratic, i.e., ∥xk+1−x∗∥≤L^∥xk−x∗∥2\| x^{k+1} - x^* \| \leq \hat{L} \| x^k - x^* \|^2∥xk+1−x∗∥≤L^∥xk−x∗∥2

Claim 1 Proof: Convergence rate for {xk}\{x^k\}{xk} is quadratic

## Define Python function to calculate objective
def my_f(x, verbose=False):
    """Evaluate function given above at point x

    Inputs:
        x - vector with 2 elements

    Outputs:
        f - function value (scalar)
    """
    # Constants
    a = np.array([0.3, 0.6, 0.2])
    b = np.array([5, 26, 3])
    c = np.array([40, 1, 10])

    # Intermediates. Recall Python indices start at 0
    u = x[0] - 0.8
    s = np.sqrt(1 - u)
    s2 = np.sqrt(1 + u)
    v = x[1] - (a[0] + a[1] * u**2 * s - a[2] * u)
    alpha = (
        -b[0] + b[1] * u**2 * s2 + b[2] * u
    )  # September 5, 2018: changed 's' to 's2'
    beta = c[0] * v**2 * (1 - c[1] * v) / (1 + c[2] * u**2)
    f = alpha * np.exp(-beta)

    if verbose:
        print("##### my_f at x = ", x, "#####")
        print("u = ", u)
        print("sqrt(1-u) = ", s)
        print("sqrt(1+u) = ", s2)
        print("v = ", v)
        print("alpha = ", alpha)
        print("beta = ", beta)
        print("f(x) = ", f)
        print("##### Done. #####\n")

    return f

def adjusted_hes(x, grad, eps2, eps3, verbose=False):

    # Estimate Hessian with finite difference
    hes = my_hes_approx(x, grad, eps2)

    # Calculate eigenvalues
    l, V = linalg.eig(hes)
    smallest_ev = np.min(np.real(l))

    # Calculate modification
    delta = 0
    if smallest_ev - eps3 < 0:
        delta = -smallest_ev + eps3

    if verbose:
        print("Added ({0:1.4e})*I in LM correction.".format(delta))

    # Adjust hessian with Levenberg-Marquardt Correction
    return V.dot(np.diag(np.real(l)) + delta * np.eye(len(x))).dot(V.T)
