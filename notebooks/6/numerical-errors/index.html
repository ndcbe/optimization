Numerical Errors: Roundoff, Cancellation, and Conditioning

Computers store real numbers approximately. The examples below compute roundoff, cancellation, and linear-system errors for the Linear Algebra Review lecture. The final experiment separates the error from rounding the data from the error of solving the stored system. For derivations, see Higham, Accuracy and Stability of Numerical Algorithms, 2nd ed. (2002), Chapters 1–2 and Theorems 7.1–7.2, pp.120–121; Watkins, Fundamentals of Matrix Computations, 2nd ed. (2002), Chapter2. Numerical results are from the displayed run; library implementations can change the final digits.

1. Machine epsilon and unit roundoff¶

For a nonzero real xxx rounded to binary64 with round-to-nearest, with no overflow or underflow, fl(x)=x(1+δ)\mathrm{fl}(x)=x(1+\delta)fl(x)=x(1+δ) and ∣δ∣≤u|\delta|\le u∣δ∣≤u. This relative-error model does not cover all subnormal values.

  • eps =2−52≈2.2⋅10−16=2^{-52}\approx2.2\cdot10^{-16}=2−52≈2.2⋅10−16 is the spacing from 1 to the next larger binary64 number.

  • Unit roundoff is u=2−53≈1.1⋅10−16u=2^{-53}\approx1.1\cdot10^{-16}u=2−53≈1.1⋅10−16. The absolute spacing changes with the exponent; eps is not the smallest positive number that can be represented.

See Higham (2002), Theorem 2.2, p.38.

2. Cancellation¶

Subtracting two nearly equal numbers cancels the digits they share. Consider (1−cos⁡x)/x2(1-\cos x)/x^2(1−cosx)/x2, whose true value tends to 1/21/21/2 as x→0x \to 0x→0. The identity 1−cos⁡x=2sin⁡2(x/2)1-\cos x = 2\sin^2(x/2)1−cosx=2sin2(x/2) gives the same function without a subtraction.

print(f"{'x':>8}  {'(1-cos x)/x^2':>16}  {'2 sin^2(x/2)/x^2':>18}")
for k in range(1, 9):

3. The quadratic formula¶

For x2+108x+1=0x^2 + 10^8 x + 1 = 0x2+108x+1=0 the small root is close to -10-8. The usual formula subtracts two nearly equal numbers, because b2−4ac≈b\sqrt{b^2 - 4ac} \approx bb2−4ac​≈b. Multiplying numerator and denominator by the conjugate gives an equivalent formula that only adds two positive numbers:

x=−b+b2−4ac2a=−2cb+b2−4ac.x = \frac{-b + \sqrt{b^2-4ac}}{2a} = \frac{-2c}{b + \sqrt{b^2-4ac}} .x=2a−b+b2−4ac​​=b+b2−4ac​−2c​.
(1)

The problem is well conditioned; only the formula is unstable. We use 50-digit decimal arithmetic to get a reference value.

a, b, c = 1.0, 1e8, 1.0
disc = np.sqrt(b**2 - 4*a*c)
x_formula = (-b + disc) / (2*a)
x_conj    = -2*c / (b + disc)

getcontext().prec = 50
A, B, C = Decimal(1), Decimal(10)**8, Decimal(1)
x_ref = float((-2*C) / (B + (B**2 - 4*A*C).sqrt()))

print(f"{'method':<22}{'small root':>22}{'relative error':>18}")
for name, val in [("quadratic formula", x_formula), ("conjugate rewrite", x_conj)]:
    print(f"{name:<22}{val:22.15e}{abs(val - x_ref)/abs(x_ref):18.2e}")
print(f"{'reference (50 digits)':<22}{x_ref:22.15e}")

4. Forward error, backward error, and conditioning¶

Let Ax=b≠0\mathbf{Ax}=\mathbf{b}\ne\mathbf{0}Ax=b=0 with nonsingular square A\mathbf{A}A. Here x\mathbf{x}x denotes the exact solution for the stored entries of A\mathbf{A}A and b\mathbf{b}b; all norms are 2-norms. For a computed x^\hat{\mathbf{x}}x^, the exact residual is r=b−Ax^\mathbf{r}=\mathbf{b}-\mathbf{A}\hat{\mathbf{x}}r=b−Ax^.

The relative forward error is ∥x^−x∥2/∥x∥2\|\hat{\mathbf{x}}-\mathbf{x}\|_2/\|\mathbf{x}\|_2∥x^−x∥2​/∥x∥2​. Allowing perturbations only in A\mathbf{A}A gives the backward error

ηA=∥r∥2∥A∥2∥x^∥2.\eta_A=\frac{\|\mathbf{r}\|_2}{\|\mathbf{A}\|_2\|\hat{\mathbf{x}}\|_2}.ηA​=∥A∥2​∥x^∥2​∥r∥2​​.
(2)

Indeed, ∥r∥2≤∥ΔA∥2∥x^∥2\|\mathbf{r}\|_2\le\|\Delta\mathbf{A}\|_2\|\hat{\mathbf{x}}\|_2∥r∥2​≤∥ΔA∥2​∥x^∥2​ for any admissible perturbation; equality is attained with ΔA=rx^T/∥x^∥22\Delta\mathbf{A}=\mathbf{r}\hat{\mathbf{x}}^\mathsf{T}/\|\hat{\mathbf{x}}\|_2^2ΔA=rx^T/∥x^∥22​. This proves Higham’s Theorem 7.1 in the matrix-only 2-norm case. Allowing simultaneous relative perturbations in both A\mathbf{A}A and b\mathbf{b}b instead gives denominator ∥A∥2∥x^∥2+∥b∥2\|\mathbf{A}\|_2\|\hat{\mathbf{x}}\|_2+\|\mathbf{b}\|_2∥A∥2​∥x^∥2​+∥b∥2​.

With K2=∥A∥2∥A−1∥2K_2=\|\mathbf{A}\|_2\|\mathbf{A}^{-1}\|_2K2​=∥A∥2​∥A−1∥2​, two valid forward bounds are

∥x^−x∥2∥x∥2≤K2∥r∥2∥b∥2,∥x^−x∥2∥x∥2≤K2ηA1−K2ηAif K2ηA<1.\begin{aligned} \frac{\|\hat{\mathbf{x}}-\mathbf{x}\|_2}{\|\mathbf{x}\|_2}&\le K_2\frac{\|\mathbf{r}\|_2}{\|\mathbf{b}\|_2},\\ \frac{\|\hat{\mathbf{x}}-\mathbf{x}\|_2}{\|\mathbf{x}\|_2}&\le\frac{K_2\eta_A}{1-K_2\eta_A}\quad\text{if }K_2\eta_A<1. \end{aligned}∥x∥2​∥x^−x∥2​​∥x∥2​∥x^−x∥2​​​≤K2​∥b∥2​∥r∥2​​,≤1−K2​ηA​K2​ηA​​if K2​ηA​<1.​
(3)

The first follows from x−x^=A−1r\mathbf{x}-\hat{\mathbf{x}}=\mathbf{A}^{-1}\mathbf{r}x−x^=A−1r and ∥b∥2≤∥A∥2∥x∥2\|\mathbf{b}\|_2\le\|\mathbf{A}\|_2\|\mathbf{x}\|_2∥b∥2​≤∥A∥2​∥x∥2​. For the second, first bound the error by K2ηA∥x^∥2K_2\eta_A\|\hat{\mathbf{x}}\|_2K2​ηA​∥x^∥2​, then use ∥x^∥2≤∥x∥2+∥x^−x∥2\|\hat{\mathbf{x}}\|_2\le\|\mathbf{x}\|_2+\|\hat{\mathbf{x}}-\mathbf{x}\|_2∥x^∥2​≤∥x∥2​+∥x^−x∥2​ and rearrange. Thus K2ηAK_2\eta_AK2​ηA​ alone is a first-order rule, not this finite bound. Theorems 7.1–7.2, pp.120–121, specify the perturbation model.

Push addition errors back onto the operands¶

Assume both additions stay in the normal floating-point range and satisfy the round-to-nearest model above. If s^=fl(fl(x+y)+z)\widehat s=\mathrm{fl}(\mathrm{fl}(x+y)+z)s=fl(fl(x+y)+z), then for ∣δ1∣,∣δ2∣≤u|\delta_1|,|\delta_2|\le u∣δ1​∣,∣δ2​∣≤u,

s^=((x+y)(1+δ1)+z)(1+δ2)=x(1+ϵ1)+y(1+ϵ2)+z(1+ϵ3).\begin{aligned} \widehat s&=((x+y)(1+\delta_1)+z)(1+\delta_2)\\ &=x(1+\epsilon_1)+y(1+\epsilon_2)+z(1+\epsilon_3). \end{aligned}s​=((x+y)(1+δ1​)+z)(1+δ2​)=x(1+ϵ1​)+y(1+ϵ2​)+z(1+ϵ3​).​
(4)

where ϵ1=ϵ2=δ1+δ2+δ1δ2\epsilon_1=\epsilon_2=\delta_1+\delta_2+\delta_1\delta_2ϵ1​=ϵ2​=δ1​+δ2​+δ1​δ2​ and ϵ3=δ2\epsilon_3=\delta_2ϵ3​=δ2​. Hence ∣ϵ1∣,∣ϵ2∣≤2u+u2|\epsilon_1|,|\epsilon_2|\le2u+u^2∣ϵ1​∣,∣ϵ2​∣≤2u+u2 and ∣ϵ3∣≤u|\epsilon_3|\le u∣ϵ3​∣≤u. The computed sum is the exact sum of slightly perturbed operands. This is a backward-error interpretation, even when cancellation makes the relative forward error large compared with the small exact sum. A different association can produce a different computed sum. See Watkins (2002), §2.5, for this operand-perturbation approach.

Hilbert experiment: distinguish assembly error and solve error¶

Choose x0=1\mathbf{x}_0=\mathbf{1}x0​=1 and form b = A @ x0 in binary64 using the stored Hilbert matrix. Because this multiplication rounds, x0\mathbf{x}_0x0​ need not solve the stored system exactly. The cell converts every stored binary64 value exactly to a high-precision number. At 100 decimal digits it solves that stored system, evaluates its residual, and computes singular values. It repeats the calculation at 160 digits to check reference convergence. These are numerical high-precision checks, not interval-certified bounds.

assembly measures ∥x−x0∥2/∥x0∥2\|\mathbf{x}-\mathbf{x}_0\|_2/\|\mathbf{x}_0\|_2∥x−x0​∥2​/∥x0​∥2​; forward measures the solve error relative to x\mathbf{x}x. res64 is the normalized residual evaluated in ordinary binary64, while resHP evaluates the residual of the same stored data and solution in high precision. A printed zero in res64 need not mean the exact residual is zero. A-bound is shown only when K2ηA<1K_2\eta_A<1K2​ηA​<1; b-bound is K2∥r∥2/∥b∥2K_2\|\mathbf{r}\|_2/\|\mathbf{b}\|_2K2​∥r∥2​/∥b∥2​.

def stored_system_errors(A, b, xhat, digits):
    """Reference the exact binary64 entries, evaluated at `digits` decimals."""
    with mp.workdps(digits):
        Am = mp.matrix([[mp.mpf(float(value)) for value in row] for row in A])
        bm = mp.matrix([mp.mpf(float(value)) for value in b])
        hm = mp.matrix([mp.mpf(float(value)) for value in xhat])
        xm = mp.lu_solve(Am, bm)
        singular = mp.svd(Am, compute_uv=False)
        normA, sigma_min = singular[0], singular[len(singular)-1]
        condition = normA / sigma_min
        residual = mp.norm(bm - Am * hm)
        forward = mp.norm(hm - xm) / mp.norm(xm)
        assembly = mp.norm(xm - mp.ones(len(b), 1)) / mp.sqrt(len(b))
        eta = residual / (normA * mp.norm(hm))
        rel_residual = residual / mp.norm(bm)
        product = condition * eta
        b_bound = condition * rel_residual
        a_bound = product / (1-product) if product < 1 else None
        assert forward <= b_bound * (1 + mp.mpf('1e-60')) + mp.mpf('1e-70')
        if a_bound is not None:
            assert forward <= a_bound * (1 + mp.mpf('1e-60')) + mp.mpf('1e-70')
        values = dict(condition_2=condition, backward_A=eta, forward=forward,
                      assembly=assembly, relative_residual_high_precision=rel_residual,
                      bound_b=b_bound, bound_A=a_bound)
        return {key: None if val is None else float(val) for key, val in values.items()}

rows = []
for n in range(2, 13):
    A = linalg.hilbert(n)
    x0 = np.ones(n)
    b = A @ x0
    xhat = linalg.solve(A, b)
    measured = stored_system_errors(A, b, xhat, 100)
    repeated = stored_system_errors(A, b, xhat, 160)
    for key in measured:
        if measured[key] is None:
            assert repeated[key] is None
        else:
            assert np.isclose(measured[key], repeated[key], rtol=1e-12, atol=1e-65)
    measured.update(n=n, A=A.tolist(), b=b.tolist(), xhat=xhat.tolist(),
                    relative_residual_binary64=float(np.linalg.norm(b-A @ xhat) / np.linalg.norm(b)))
    rows.append(measured)

Read the measured errors and both bounds together. Increasing condition number permits a larger forward error even when the backward error is small, but a large condition number does not force every solve to be inaccurate. The assembly column exposes error introduced before the solve. Comparing res64 and resHP shows why an ordinary computed residual is an estimate of the exact residual.

The assertions compare forward error with the appropriate bounds for the stored problem. They do not compare it with K2ηAK_2\eta_AK2​ηA​ alone. A small measured backward error supports the quality of this solve; a proof of backward stability for an algorithm requires an error analysis over its input class. The high-precision singular values also avoid using a binary64 condition-number estimate as the reference at the binary64 precision limit.
