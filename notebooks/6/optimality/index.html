Quantified minimizer definitions¶

For f:Rn→Rf:\mathbb R^n\to\mathbb Rf:Rn→R, let B(x∗,r)={x:∥x−x∗∥<r}B(\mathbf x^*,r)=\{\mathbf x:\|\mathbf x-\mathbf x^*\|<r\}B(x∗,r)={x:∥x−x∗∥<r} with r>0r>0r>0. A global minimizer satisfies f(x∗)≤f(x)f(\mathbf x^*)\le f(\mathbf x)f(x∗)≤f(x) for every x∈Rn\mathbf x\in\mathbb R^nx∈Rn. A local minimizer satisfies this inequality for every x∈B(x∗,r)\mathbf x\in B(\mathbf x^*,r)x∈B(x∗,r) for some r>0r>0r>0. Strict local minimality requires f(x∗)<f(x)f(\mathbf x^*)<f(\mathbf x)f(x∗)<f(x) for every other point in that ball. Isolation means that x∗\mathbf x^*x∗ is the only local minimizer in some ball.

Isolated implies strict¶

Let x∗\mathbf x^*x∗ be a local minimizer isolated among local minimizers. Choose a radius rrr for local minimality and a radius RRR for isolation. If strictness fails, every sufficiently small neighborhood contains a distinct y\mathbf yy with f(y)=f(x∗)f(\mathbf y)=f(\mathbf x^*)f(y)=f(x∗); choose it inside both balls. Choose 0<ρ<r−∥y−x∗∥0<\rho<r-\|\mathbf y-\mathbf x^*\|0<ρ<r−∥y−x∗∥. Every z∈B(y,ρ)\mathbf z\in B(\mathbf y,\rho)z∈B(y,ρ) belongs to B(x∗,r)B(\mathbf x^*,r)B(x∗,r) by the triangle inequality, and therefore f(z)≥f(x∗)=f(y)f(\mathbf z)\ge f(\mathbf x^*)=f(\mathbf y)f(z)≥f(x∗)=f(y). This makes y\mathbf yy a second local minimizer inside the isolating ball, a contradiction. The converse fails in the oscillatory example below.

For nonempty A⊂RA\subset\mathbb RA⊂R bounded below, m=inf⁡Am=\inf Am=infA means m≤am\le am≤a for all a∈Aa\in Aa∈A, and for each ϵ>0\epsilon>0ϵ>0 there is a∈Aa\in Aa∈A with a<m+ϵa<m+\epsilona<m+ϵ. Weierstrass says that a continuous function on a nonempty compact set attains its minimum and maximum (see the Real Analysis Review lecture). Convexity on a convex domain means f(θxa+(1−θ)xb)≤θf(xa)+(1−θ)f(xb)f(\theta\mathbf x_a+(1-\theta)\mathbf x_b)\le\theta f(\mathbf x_a)+(1-\theta)f(\mathbf x_b)f(θxa​+(1−θ)xb​)≤θf(xa​)+(1−θ)f(xb​) for all points and 0<θ<10<\theta<10<θ<1. If xa\mathbf x_axa​ is local but not global, choose xb\mathbf x_bxb​ with f(xb)<f(xa)f(\mathbf x_b)<f(\mathbf x_a)f(xb​)<f(xa​); xb\mathbf x_bxb​ need not be local. Sufficient conditions: strictness and isolation¶

Suppose ∇f(x∗)=0\nabla f(\mathbf x^*)=0∇f(x∗)=0 and ∇2f(x∗)≻0\nabla^2 f(\mathbf x^*)\succ0∇2f(x∗)≻0. Continuity keeps the Hessian positive definite in a sufficiently small ball (the smallest eigenvalue remains positive). For every nonzero displacement staying in that ball, the second Taylor identity gives a strictly positive objective change. This proves strict local minimality.

If another local minimizer y\mathbf yy lay in that ball, its gradient would also be zero. With p=y−x∗\mathbf p=\mathbf y-\mathbf x^*p=y−x∗, convexity of the ball keeps the whole segment inside it. Multiplying the gradient integral identity by pT\mathbf p^TpT gives 0=∫01pT∇2f(x∗+tp)p dt>00=\int_0^1\mathbf p^T\nabla^2 f(\mathbf x^*+t\mathbf p)\mathbf p\,dt>00=∫01​pT∇2f(x∗+tp)pdt>0, a contradiction. This proves isolation. The certificate is local and gives no comparison with distant basins.

    a = np.array([0.3, 0.6, 0.2])

    return f

Finite Difference Gradient and Hessian¶

We need to calculate ∇f(x)\nabla f(\mathbf{x})∇f(x) and ∇2f(x)\nabla^2 f(\mathbf{x})∇2f(x) to analyze a given point. Below are functions that implement a central finite difference. Another option is to analytically calculate the derivatives or use automatic differentiation.

## Gradient
def my_grad(x, verbose=True, eps=1e-6):
    """
    Calculate gradient of function my_f using central difference formula

    Inputs:
        x - point for which to evaluate gradient

    Outputs:
        grad - gradient (vector)

    Assumptions:
        1. my_f is defined
        2. input x has the correct number of elements for my_f
        3. my_f is continuous and differentiable
    """

    n = len(x)
    grad = np.zeros(n)

    if verbose:
        print("***** my_grad at x = ", x, "*****")

    for i in range(0, n):

        # Create vector of zeros except eps in position i
        e = np.zeros(n)
        e[i] = eps

        # Finite difference formula
        my_f_plus = my_f(x + e)
        my_f_minus = my_f(x - e)

        # Diagnostics
        if verbose:
            print("e[", i, "] = ", e)
            print("f(x + e[", i, "]) = ", my_f_plus)
            print("f(x - e[", i, "]) = ", my_f_minus)

        grad[i] = (my_f_plus - my_f_minus) / (2 * eps)

    if verbose:
        print("***** Done. ***** \n")

    return grad

## Hessian
def my_hes(x, eps=1e-4, grad_eps=1e-6):
    """
    Calculate Hessian of function my_f using central difference formula and my_grad

    Inputs:
        x - point for which to evaluate gradient

    Outputs:
        H - Hessian (matrix)

    Assumptions:
        1. my_f and my_grad are defined
        2. input x has the correct number of elements for my_f
        3. my_f is continuous and twice differentiable
        4. No mistakes in my_grad
    """

    n = len(x)
    H = np.zeros([n, n])

    for i in range(0, n):
        # Create vector of zeros except eps in position i
        e = np.zeros(n)
        e[i] = eps

        # Evaluate gradient twice
        grad_plus = my_grad(x + e, verbose=False, eps=grad_eps)
        grad_minus = my_grad(x - e, verbose=False, eps=grad_eps)

        # Notice we are building the Hessian by column (or row)
        H[:, i] = (grad_plus - grad_minus) / (2 * eps)

    """
    Note: This is not very efficient. You can probably think of several 
    performance improvements. We will learn more practical ways to approximate 
    the Hessian for optimization algorithms in the next few lectures.
    """

    return H

Continuous Optimization Algorithms¶

Derivative-free methods use objective values with less derivative structure; classical direct search generally scales poorly as the number of variables grows. Gradient-based methods exploit smoothness to choose steps and often solve local problems quickly. Neither family name alone guarantees a global solution; the assumptions and convergence result for the particular method matter.

Function-value complexity versus stationarity¶

A global guarantee and a small gradient are different targets. For an objective on [0,1]n[0,1]^n[0,1]n that is LLL-Lipschitz in the infinity norm, a function-value oracle must, in the worst case, use at least

⌊L2ε⌋n\left\lfloor\frac{L}{2\varepsilon}\right\rfloor^n⌊2εL​⌋n
(10)

A uniform grid gives a matching-order upper bound with ⌊L/(2ε)⌋+1\lfloor L/(2\varepsilon)\rfloor+1⌊L/(2ε)⌋+1 points per coordinate. An unsampled box can contain a Lipschitz depression consistent with every observed value; the guarantee must account for that possibility.
