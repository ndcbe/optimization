Concepts¶

Feasible Sequence

  • Feasible point xˉ\bar{x}xˉ

  • Sequence {xk}\{x^k\}{xk} (e.g., optimization algorithm iterations)

  • Limit lim⁡k→∞{xk}=xˉ\lim_{k \rightarrow \infty} \{x^k\} = \bar{x}limk→∞​{xk}=xˉ

  • xkx^{k}xk feasible for all k≥Kk \geq Kk≥K where KKK is sufficiently large

Limiting Direction ddd

lim⁡k→∞xk−xˉ∣∣xk−xˉ∣∣=d\lim_{k \rightarrow \infty} \frac{x^k - \bar{x}}{|| x^k - \bar{x} || } = dk→∞lim​∣∣xk−xˉ∣∣xk−xˉ​=d

Recall the ball rolling example.

  • Feasible sequence: path of the ball rolling to rest at local min

  • Limiting direction: tangent to the path and opposite of the direction the ball is rolling

In the above picture:

  • Green sequence is always feasible and thus is a feasible sequence

  • Blue sequence becomes feasible starting with x3x^3x3 and is a feasible sequence

Theorem 4.8: If x∗x^*x∗ is a solution of (NLP), then all feasible sequences leading to x∗x^*x∗ must satisfy

∇f(x∗)Td≥0\nabla f(x^*)^T d \geq 0∇f(x∗)Td≥0

where ddd is the limiting direction of the feasible sequence.

Ball analogy: can only roll down the hill. Cannot come from downhill direction (and still be feasible).

Big Picture

Constraint qualifications act as the link between KKT conditions (which we numerical solve) and limiting directions (Theorem 4.8).

Key questions:

  • Do ∇g\nabla g∇g and ∇h\nabla h∇h properly characterize/identify local solutions?

Linear Constrained Optimization Problems¶

Consider a nonlinear objective with linear constraints:

min⁡xf(x)s.t.Bx≤b,Cx=c.\begin{aligned} \min_x\quad & f(x) \\ \text{s.t.}\quad & Bx \le b,\qquad Cx=c. \end{aligned}xmin​s.t.​f(x)Bx≤b,Cx=c.​
(1)

For this structure, the linearized feasible-direction cone exactly represents the limiting directions of feasible sequences. Consequently, if x∗x^*x∗ is a local solution, then

∇f(x∗)Td≥0\nabla f(x^*)^T d \ge 0∇f(x∗)Td≥0
(2)

for every ddd satisfying

Cd=0,Bid≤0for every active row i.Cd=0,\qquad B_i d\le 0 \quad \text{for every active row }i.Cd=0,Bi​d≤0for every active row i.
(3)

Equivalently, the KKT conditions hold at x∗x^*x∗:

∇f(x∗)+BTu∗+CTv∗=0,Bx∗≤b,Cx∗=c,(Bx∗−b)Tu∗=0,u∗≥0.\begin{aligned} \nabla f(x^*)+B^T u^*+C^T v^*&=0,\\ Bx^*&\le b,\qquad Cx^*=c,\\ (Bx^*-b)^T u^*&=0,\qquad u^*\ge 0. \end{aligned}∇f(x∗)+BTu∗+CTv∗Bx∗(Bx∗−b)Tu∗​=0,≤b,Cx∗=c,=0,u∗≥0.​
(4)

If fff is convex, any point satisfying these conditions is a global solution. (Biegler, Section 4.3.)

Constraint Qualifications¶

Constraint qualifications are the link between KKT conditions and limiting directions (Theorem 4.8).

Main idea: Ensure active constraints are not “too nonlinear” and KKT conditions adequately describe limit directions.

Linear Independence Constraint Qualification (LICQ)¶

Definition 4.12 Given a local solution x∗x^*x∗ to:

min⁡f(x)s.t.g(x)≤0, h(x)=0,\min f(x) \quad \text{s.t.} \quad g(x) \leq 0, \, h(x) = 0,minf(x)s.t.g(x)≤0,h(x)=0,

with active set A(x∗)\mathcal{A}(x^*)A(x∗), LICQ holds if:

∇gi(x∗),∇hi(x∗) for i∈A(x∗)\nabla g_i(x^*), \nabla h_i(x^*) \, \text{for} \, i \in \mathcal{A}(x^*)∇gi​(x∗),∇hi​(x∗)fori∈A(x∗)

are linearly independent.

i.e., the part of the Jacobian corresponding to the active set is full rank.

Does LICQ hold for the example? No.

Lemma 4.13 Consider “the cone”:

∇hi(x∗)Td=0,∇gi(x∗)Td≤0, i∈A(x∗)\nabla h_i(x^*)^T d = 0, \quad \nabla g_i(x^*)^T d \leq 0, \, i \in \mathcal{A}(x^*)∇hi​(x∗)Td=0,∇gi​(x∗)Td≤0,i∈A(x∗)

  1. The set of limiting directions for all feasible sequences is a subset of “the cone”.

  2. If LICQ holds, “the cone” is equivalent to the set of limiting directions for all feasible sequences.

  3. Consider all limiting directions in “the cone” with ∥d∥=1\|d\| = 1∥d∥=1. When LICQ holds, a feasible sequence {xk}\{x^k\}{xk}:

    xk=x∗+td+o(t)x^k = x^* + t d + o(t)xk=x∗+td+o(t)

    can always be constructed to satisfy:

    hi(xk)=t∇hi(x∗)Td=0,h_i(x^k) = t \nabla h_i(x^*)^T d = 0,hi​(xk)=t∇hi​(x∗)Td=0,
    gi(xk)=t∇gi(x∗)Td≤0, i∈A(x∗)g_i(x^k) = t \nabla g_i(x^*)^T d \leq 0, \, i \in \mathcal{A}(x^*)gi​(xk)=t∇gi​(x∗)Td≤0,i∈A(x∗)

    for some small positive ttt with lim⁡t→0\lim t \to 0limt→0.

What does this mean? When LICQ holds, it is always possible to construct a feasible sequence in the limiting direction. This is important for algorithms.

Theorem 4.14: Consider local solution x∗x^*x∗. If LICQ holds at x∗x^*x∗, then:

  1. The KKT conditions are satisfied.

  2. If:

    • (i) f(x)f(x)f(x) and g(x)g(x)g(x) are convex,

    • (ii) h(x)h(x)h(x) is linear,

    and (iii) the KKT conditions are satisfied,

    then x∗x^*x∗ is a global solution (this implies optimality).

Theorem 4.15 LICQ and Multipliers

Given a point x∗x^*x∗ that satisfies the KKT conditions with multipliers u∗u^*u∗ and v∗v^*v∗, and with active set A(x∗)\mathcal{A}(x^*)A(x∗). If LICQ holds, then u∗u^*u∗ and v∗v^*v∗ are unique.

Mangasarian-Fromovitz Constraint Qualification (MFCQ)¶

What can we say if LICQ does not hold?

Definition 4.16 Mangasarian-Fromovitz Constraint Qualification (MFCQ)

Given:

  • A local solution x∗x^*x∗

  • Active set A(x∗)\mathcal{A}(x^*)A(x∗)

MFCQ is defined by:

  1. Linear independence of equality constraint gradients.

  2. There exists a search direction ddd such that:

    ∇gi(x∗)Td<0,∇hi(x∗)Td=0,i∈A(x∗).\nabla g_i(x^*)^T d < 0, \quad \nabla h_i(x^*)^T d = 0, \quad i \in \mathcal{A}(x^*).∇gi​(x∗)Td<0,∇hi​(x∗)Td=0,i∈A(x∗).

Key Properties

  1. LICQ   ⟹  \implies⟹ MFCQ.

  2. If MFCQ holds, then multipliers u∗u^*u∗ and v∗v^*v∗ are bounded (but not necessarily unique).

Does MFCQ hold for the example?

No ddd satisfies:

[010−1]d<0\begin{bmatrix} 0 & 1 \\ 0 & -1 \end{bmatrix} d < 0[00​1−1​]d<0

Thus, MFCQ does not hold!

Example Revisited: Solve with Pyomo¶

import pyomo.environ as pyo
from pyomo.environ import (
    ConcreteModel,
    Var,
    Objective,
    Constraint,
    SolverFactory,
    Suffix,
    minimize,
    value,
)

## Create concrete Pyomo model
m = ConcreteModel()

## Set up to extract dual variables after model solve.
m.dual = Suffix(direction=Suffix.IMPORT)

## Declare variables with initial values
m.x1 = Var(initialize=1)
m.x2 = Var(initialize=1)

## Declare objective
m.OBJ = Objective(expr=m.x1, sense=minimize)

m.g1 = Constraint(expr=m.x2 <= m.x1**3)

m.g2 = Constraint(expr=-m.x1**3 <= m.x2)

## Specify IPOPT as solver
solver = SolverFactory("ipopt")

## Solve the model
results = solver.solve(m, tee=True)
assert pyo.check_optimal_termination(results), (
    f"Solve failed: status={results.solver.status}, "
    f"termination={results.solver.termination_condition}"
)

## Return the solution
print("x1 = ", value(m.x1))
print("x2 = ", value(m.x2))
print("\n")

## Inspect dual variables
m.dual.display()
