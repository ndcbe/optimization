This tells Pyomo that the value of the parameter may change in the future, and allows the user to change the parameter value and resolve the problem without the need to rebuild the entire model each time. Integer cuts¶

Often, it can be important to find not only the “best” solution, but a number of solutions that are equally optimal, or close to optimal. For discrete optimization problems, this can be done using something known as an integer cut. Consider again the knapsack problem where the choice of which items to select is a discrete variable xi∀i∈Ax_i \forall i \in Axi​∀i∈A. Let xi∗x_i^*xi∗​ be a particular set of xxx values we want to remove from the feasible solution space. We define an integer cut using two sets. The first set S0S_0S0​ contains the indices for those variables whose current solution is 0, and the second set S1S_1S1​ consists of indices for those variables whose current solution is 1. Given these two sets, an integer cut constraint that would prevent such a solution from appearing again is defined by,

∑i∈S0x[i]+∑i∈S1(1−xi)≥1\sum_{i \in S_0}x[i] + \sum_{i \in S_1}(1-x_i) \geq 1∑i∈S0​​x[i]+∑i∈S1​​(1−xi​)≥1

Reactor design problem (Bynum et al., 2021; Bequette, 2003)¶

Here we will consider a chemical reactor designed to produce product B from reactant A using a reaction scheme known as the Van de Vusse reaction:

A→k1B→k2CA \overset{k_1}{\rightarrow} B \overset{k_2}{\rightarrow} CA→k1​B→k2​C

2A→k3D2A \overset{k_3}{\rightarrow} D2A→k3​D

Under appropriate assumptions, FFF is the volumetric flowrate through the tank. The concentration of component A in the feed is cAfc_{Af}cAf​, and the concentrations in the reactor are equivalent to the concentrations of each component flowing out of the reactor, given by cAc_AcA​, cBc_BcB​, cCc_CcC​, and cDc_DcD​.

If the reactor is too small, we will not produce sufficient quantity of B, and if the reactor is too large, much of B will be further reacted to form the undesired product C. Therefore, our goal is to solve for the reactor volume that maximizes the outlet concentration for product B.

The steady-state mole balances for each of the four components are given by

0=FVcAf−FVcA−k1cA−2k3cA20=\frac{F}{V}c_{Af}-\frac{F}{V}c_A-k_1c_A-2k_3c^2_A0=VF​cAf​−VF​cA​−k1​cA​−2k3​cA2​

0=−FVcB+k1cA−k2cB0=-\frac{F}{V}c_{B}+k_1c_A-k_2c_B0=−VF​cB​+k1​cA​−k2​cB​

0=−FVcC+k2cB0=-\frac{F}{V}c_{C}+k_2c_B0=−VF​cC​+k2​cB​

0=−FVcD+k3cA20=-\frac{F}{V}c_{D}+k_3c^2_A0=−VF​cD​+k3​cA2​

Formulate and solve this optimization problem using Pyomo. Since the volumetric flowrate FFF always appears as the numerator over the reactor volume VVV, it is common to consider this ratio as a single variable, called the space-velocity SVSVSV.
