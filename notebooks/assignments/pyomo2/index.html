1-I. Integer cuts¶

Often, it can be important to find not only the “best” solution, but a number of solutions that are equally optimal, or close to optimal. For discrete optimization problems, this can be done using something known as an integer cut. Consider again the knapsack problem where the choice of which items to select is a discrete variable xi∀i∈Ax_i \forall i \in Axi​∀i∈A. Let xi∗x_i^*xi∗​ be a particular set of x\mathbf{x}x values we want to remove from the feasible solution space. We define an integer cut using two sets. The first set S0S_0S0​ contains the indices for those variables whose current solution is 0, and the second set S1S_1S1​ consists of indices for those variables whose current solution is 1. Given these two sets, an integer cut constraint that would prevent such a solution from appearing again is defined by,

∑i∈S0x[i]+∑i∈S1(1−xi)≥1\sum_{i \in S_0}x[i] + \sum_{i \in S_1}(1-x_i) \geq 1∑i∈S0​​x[i]+∑i∈S1​​(1−xi​)≥1
